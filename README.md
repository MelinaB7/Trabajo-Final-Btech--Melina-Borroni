# 📇 ABM de Contactos con React y Firestore

Aplicación web desarrollada con **React** que permite gestionar contactos mediante un sistema **ABM (Alta, Baja y Modificación)**.

El usuario puede agregar contactos a través de un formulario donde ingresa:

- Nombre
- Teléfono
- Correo electrónico

Los datos se almacenan y sincronizan en tiempo real con **Firebase Firestore**.

---

# 🚀 Funcionalidades

- ➕ Crear nuevos contactos mediante un formulario  
- 📋 Visualizar la lista de contactos guardados  
- ✏️ Editar los datos de un contacto existente  
- 🗑️ Eliminar contactos
- 🔄 Sincronización en tiempo real con la base de datos  
- 📋 Visualizar los contactos obtenidos por medio de la API 

---

# 🛠 Tecnologías utilizadas

- React
- Firebase Firestore
- JavaScript
- CSS

---

# 📦 Librerías utilizadas

### SweetAlert2
Utilizada para mostrar ventanas emergentes más estéticas al editar los contactos, reemplazando el `prompt` nativo de JavaScript.

### Lucide React
Librería de iconos utilizada para los botones de **editar** y **eliminar**.

---

# 🌐 API pública utilizada
Este proyecto utiliza la API pública https://jsonplaceholder.typicode.com/users para obtener usuarios de prueba.
Los mismos se muestran debajo de los contactos que genera el usuario con el titulo "Otros contactos"

---

# 🎨 Estilos

Los estilos de la aplicación están desarrollados utilizando **CSS**, organizados por componente para mantener una estructura clara y escalable.
